\begin{frame}[shrink]{Aprendizaje automático para la estimación de
efectos causales}
\phantomsection\label{aprendizaje-automuxe1tico-para-la-estimaciuxf3n-de-efectos-causales}

\begin{columns}[T]
\begin{column}{0.3\linewidth}
\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\textbf{Objetivo}: estimar el parámetro \(\tau\) para la expresión:
\[y=\tau D+g(X)+\epsilon\]

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

Con \textbf{datos observacionales} \(\to\) posible confusión en \(X\):

\[D= m(X)+\eta\]

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}
\end{column}

\begin{column}{0.05\linewidth}
\end{column}

\begin{column}{0.65\linewidth}

\textbf{¿Por qué aprendizaje automático?}

\begin{itemize}
\tightlist
\item
  Elevada dimensionalidad de \(X\).
\item
  Datos no tabulares (p.e. texto o imágenes).
\item
  Flexibilidad para aproximar \(g\) y \(m\).
\end{itemize}
\end{column}

\begin{frame}{Aplicación \emph{naive} de métodos de aprendizaje
automático}
\phantomsection\label{aplicaciuxf3n-naive-de-muxe9todos-de-aprendizaje-automuxe1tico-1}
~

\begin{columns}[T]
\begin{column}{0.3\linewidth}
\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\textbf{Problema 1}

Los modelos de aprendizaje automático regularizan (de forma explícita o
implícita) los predictores, introduciendo el denominado \emph{sesgo de
regularización}.

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\textbf{Problema 2}

Utilizar el mismo conjunto de datos para estimar una función y realizar
predicciones introduce \emph{sesgo por sobreajuste}.

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}
\end{column}

\begin{column}{0.05\linewidth}
\end{column}

\begin{column}{0.65\linewidth}
Aproximación ingenua para la estimación de \(\tau\) en
\[y=\tau D+g(X)+\epsilon,\]

\begin{enumerate}
\tightlist
\item
  Aprender de los datos un modelo flexible \(\hat{g}\);
\item
  Obtener una versión residualizada de la respuesta
  \(\tilde{y}=y-\hat{g}(X)\);
\item
  Recuperar el efecto \(\tau\) por la regresión de \(\tilde{y}\) sobre
  \(D\).
\end{enumerate}

\textbf{Sesgo de regularización}: la estimación \(\hat{g}\) selecciona
variables \(X\) por su capacidad para \textbf{predecir \(y\)} pudiendo
atenuar/eliminar un control \(x^*\) poco correlacionado con \(y\) (y que
sea muy relevante para explicar \(D\)). En este caso el modelo de
segunda etapa atribuirá parte de la relación de \(x^*\) con \(D\) a
\(\tau\): se trata de un tipo de \textbf{sesgo por variable omitida}.

\textbf{Sesgo por sobreajuste}: entrenamiento y predicción sobre las
mismas observaciones atenúa parte del efecto causal (lo absorben los
residuos de \(y\)) y aumenta la varianza resiual del tratamiento (la
estimación de \(\tau\) y su error estándar deja de ser fiable).
\end{column}
\end{columns}
\end{frame}

\begin{frame}[shrink]{Double (Debiased) Machine Learning}
\phantomsection\label{double-debiased-machine-learning}
~

\begin{columns}[T]
\begin{column}{0.3\linewidth}
\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

Estimador de efecto causal en dos etapas

\begin{itemize}
\tightlist
\item
  Primera etapa

  \begin{enumerate}
  \tightlist
  \item
    Entrenar funciones \(\hat{g}\) y \(\hat{m}\) para respuesta y
    tratamiento.
  \item
    Generar versiones residualizadas\\
    \(\tilde{y}=y-\hat{g}(X)\) y \(\tilde{D}=D-\hat{m}(X)\) (separar
    entrenamiento/predicción)
  \end{enumerate}
\item
  Segunda etapa: estimar la regresión
  \(\tilde{y}=\tau \tilde{D}+\epsilon\)
\end{itemize}
